# SmartLamp
Умный светильник — мой первый учебный проект на Arduino.

Это мой первый учебный проект, связанный с электроникой и программированием микроконтроллеров.

Я решил начать знакомство с Arduino с создания простого умного светильника. Для меня это возможность на практике разобраться с подключением электронных компонентов, работой датчиков, написанием кода и взаимодействием программной и аппаратной частей устройства.

В дальнейшем я планирую перейти к ESP32 и более сложным проектам в области электроники и умного дома.

## 📦 Что находится в репозитории

Здесь я собрал всё необходимое для повторения проекта:

- Список используемых компонентов.
- Схему подключения.
- Распиновку компонентов.
- Исходный код программы.
- Дополнительные материалы по сборке.

## 💡 Для кого этот проект?

В первую очередь — для таких же начинающих, которые только знакомятся с Arduino и хотят попробовать собрать что-то своими руками.

Я не претендую на экспертность и рассматриваю этот проект как часть собственного обучения. Поэтому здесь могут встречаться не самые оптимальные решения, ошибки и моменты, которые впоследствии захочется улучшить.
